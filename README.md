# Sivasankar's keyboard
One day, I was thinking about making a custom keyboard which would be suitable for me from scratch but that was too costly. After i joined hackclub's stasis i thought why not to build our keyboard as the stasis event funds us. So i started making a custom 75 percent keyboard from scratch using fusion 360 and kicad. I used the layout cool 84 which had 84 keys in it.
